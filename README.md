# 🛰️ Palisades From Space

**🌿 Before → 🔥 Fire → 🌱 Recovery**

My little satellite project: using Python and Sentinel-2 Level-2A imagery to explore how the Palisades landscape changed across January 2025 and September 2026.

I compare near-infrared and shortwave-infrared light with the **Normalized Burn Ratio (NBR)**. Across the same clear land pixels, mean NBR goes **0.187 → −0.121 → 0.075**: a sharp drop, then a partial rebound in the satellite signal. Seasons and the study box matter too.
